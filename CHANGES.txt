AMF 4.8.1

verification now write complete output to named logs and include that output
in the error dialog. INSTALL.cmd launches the PowerShell installer from the
correct folder, avoiding Explorer working-directory issues. Use INSTALL.cmd
or s.vbs; do not run a stale Setup.exe copied from an earlier release.

installer now selects a real Python installation, verifies it before use, and
stores the resolved interpreter path. This prevents the callback/redirect
stub error seen on fresh devices.

AMF 4.5.1 update

Installation repair
Windows PowerShell now waits for verification and captures the real exit
code. The test uses native Windows fonts without opening a window.
The version check previously imported app.py from a different working
directory and failed to locate amf_features.py. A dedicated verification
script now resolves sibling imports and checks the version and application
window using temporary state. The check runs before Windows registration.
Failures are recorded in install-check.log and install-check-error.log in
the installation folder.

Run s.vbs from this folder to launch the updated installer. Keep the entire
folder together. It uses the existing installer and preserves config/cart.

Selection
- Select Visible, Unselect Visible, Invert Visible and Clear All Selections.
- Checked search results stay checked when you change filters or sorting.
- Add Selected operates on currently visible checked results.
- Successfully added results are unchecked.
- Cart has Select All / Unselect All; Ctrl/Shift row selection is supported.

Default folders
Games:        D:\Games
Movies:       D:\Movies
Series:       D:\Series
Anime Movies: D:\Anime\Movies
Anime Series: D:\Anime\Series
Music:        D:\Music

Games categories and common game-release markers route to Games.
YTS defaults to Movies. Nyaa/anime metadata routes into Anime, with movie
keywords/category deciding the movie subfolder. Music/audio metadata routes
to Music. Classification is best effort; use the Cart Destination dropdown
to correct ambiguous titles. Custom save folders are preserved.

Clients
- qBittorrent: existing Web UI connection.
- Deluge: Web JSON-RPC, default port 8112. Log in using its Web password;
  connect the Web UI to a daemon before using AMF.
- Transmission: legacy-compatible RPC, default port 9091.
- uTorrent / Other desktop client: enter its executable path. Opens each
  torrent in that client; choose the save folder in its dialog. This mode
  does not enforce AMF's paths or confirm acceptance, so cart items remain.
- Each client retains its own connection settings.

Sources
The Pirate Bay is now the fourth enabled default source, alongside Nyaa,
1377x and YTS. Its search uses APIBay JSON because its website renders results
with JavaScript. Existing source settings are retained. Site availability
depends on the provider/network; live Pirate Bay access was not verified.

Verification
Automated checks passed for routing, folder overrides, selection persistence,
client profile switching, source migration, Pirate Bay response fixtures,
Deluge failure handling and Transmission's session handshake. The complete
Qt interface was constructed successfully. No actual torrents were submitted
and live client connections have not been tested.
